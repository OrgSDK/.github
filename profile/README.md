## A place for AI work to run

**[OrgSDK](https://github.com/OrgSDK/OrgSDK)** is a local-first platform for external AI clients to execute code and build tested, reusable actions. Run it on infrastructure you control, and connect your client through MCP.

- **Persistent projects** keep working files, plugins and run history together.
- **Reusable actions** have immutable versions, input/output contracts and isolated mocked tests.
- **Scoped access** controls what clients and runs can do, with credential permissions and human approvals.
- **Inspectable runs** retain source, results and execution events so you can understand what happened.

External clients handle reasoning and conversation. OrgSDK provides the execution workspace and durable records around the work.
